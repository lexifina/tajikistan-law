ҲУКУМАТИ ҶУМҲУРИИ ТОҶИКИСТОН
ҚАРОР
Дар бораи таъсиси Маркази идораи лоиҳаи рушди инфраструктураи маҳалли (коммуналӣ) дар Ҷумҳурии Тоҷикистон
Бо мақсади таҷдиди системаи инфраструктураи коммуналӣ ва татбиқи самараноки Созишномаи грантии байни Ҳукумати Ҷумҳурии Тоҷикистон ва Бонки Умумиҷаҳони ва мувофиқи моддаи 132 Кодекси граждании Ҷумҳурии Тоғикистон Ҳукумати Ҷумҳурии Тоҷикистон қарор мекунад:
1. Маркази идораи Лоиҳаи рушди инфраструктураи маҳалли (коммунали) дар Ҷумҳурии Тоҷикистон таъсис дода шавад.
Корхонаи воҳиди давлатии "Хоҷагии манзилию коммунали" агентии иҷроияи Лоиҳаи мазкур муайян карда шавад (Қарори Ҳукумати ҶТ аз 28.09.2005с. № 357).
2. Оинномаи замимагардидаи Маркази идораи Лоиҳаи рушди инфраструктураи маҳалли (коммунали) дар Ҷумҳурии Тоҷикистон тасдиқ карда шавад.
3. Кумитаи давлатии идораи амволи давлатии Ҷумҳурии Тоҷикистон барои ҷойгир кардани Маркази идораи Лоиҳаи рушди инфраструктураи маҳалли (коммунали) дар Ҷумҳурии Тоҷикистон ба сифати саҳми Ҳукумати Ҷумҳурии Тоҷикистон ошёнаи 4-уми бинои Корхонаи воҳиди давлатии "Хоҷагии манзилию коммуналӣ"-и Ҷумҳурии Тоҷикистонро, воқеъ дар шаҳри Душанбе, кӯчаи Н. Қаробоев 56 ҷудо намояд.
4. Маркази идораи Лоиҳаи рушди инфраструктураи маҳалли (коммунали) дар Ҷумҳурии Тоҷикистон дар мувофиқа бо Вазорати молияи Ҷумҳурии Тоҷикистон ва Бонки Умумиҷаҳонӣ сохтор, рӯйхати штати ва сметаи хароҷоти нигоҳдории дастгоҳи Маркази идораи Лоиҳаи рушди инфраструктураи маҳалли (коммунали) дар Ҷумҳурии Тоҷикистонро таҳия ва тасдиқ намояд.
