# Вазорати корҳои дохилии Ҷумҳурии Тоҷикистон Вазорати маориф ва илми Ҷумҳурии Тоҷикистон аз 13 декабри соли 2013 № 34 "Дар бораи тасдиқи Тартиби назорати фаъолияти муассисаҳои таълимӣ оид ба тайёр кардан, бозомӯзии (баланд бардоштани савияи касбии) ронандагони воситаҳои нақлиёти автомобилӣ ва бақайдгирии гурӯҳҳои таълимӣ дар воҳидҳои бақайдгирию имтиҳонотии Бозрасии давлатии автомобилӣ"
