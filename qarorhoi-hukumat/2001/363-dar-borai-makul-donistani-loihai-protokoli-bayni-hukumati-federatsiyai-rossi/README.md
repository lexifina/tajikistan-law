# Қарори Ҳукумати Ҷумҳурии Тоҷикистон аз 6 августи соли 2001, № 363 "Дар бораи маъкул донистани лоиҳаи Протоколи байни Ҳукумати Федератсияи Россия, Ҳукумати Ҷумҳурии Қазоқистон, Ҳукумати Ҷумҳурии Қирғизистон ва Ҳукумати Ҷумҳурии Тоҷикистон оид ба принсипҳо ва тартиби ҳамкорӣ ҷиҳати иҷрои Созишномаи байни Федератсияи Россия, Ҷумҳурии Қазоқистон, Ҷумҳурии Қиргизистон, Ҷумҳурии Тоҷикистон ва Ҷумҳурии Халқии Хитой дар хусуси таҳкими боварӣ дар соҳаи ҳарбӣ дар минтақаи сарҳад аз 26 апрели соли 1996 ва Созишномаи байни Федератсияи Россия, Ҷумҳурии Қазоқистон, Ҷумҳурии Қирғизистон, Ҷумҳурии Тоҷикистон ва Ҷумҳурии Халқии Хитой доир ба ихтисори мутақобилаи Қувваҳои Мусаллаҳ дар минтақаи сарҳад аз 24 апрели соли 1997"
