ҚАРОРИ МАҶЛИСИ МИЛЛИИ МАҶЛИСИ ОЛИИ ҶУМҲУРИИ ТОҶИКИСТОН
Оид ба тағйир додани номи деҳот ва деҳаҳои ноҳияи Рӯдакӣ
Пешниҳоди Ҳукумати Ҷумҳурии Тоҷикистонро "Дар бораи пешниҳоди Маҷлиси вакилони халқи ноҳияи Рӯдакӣ "Оид ба тағйир додани номи деҳот ва деҳаҳои ноҳияи Рӯдакӣ" баррасӣ намуда, мутобиқи моддаи 23 Қонуни конститутсионии Ҷумҳурии Тоҷикистон "Дар бораи тартиби ҳалли масъалаҳои сохти марзиву маъмурии Ҷумҳурии Тоҷикистон" Маҷлиси миллии Маҷлиси Олии Ҷумҳурии Тоҷикистон қарор мекунад:
1. Номи деҳоти Қарахон Сардоров ба деҳоти Эсанбой ва номи деҳаҳои зерини он:
- деҳаи Оқбулок ба деҳаи Сафедчашма
- деҳаи Қаробулок ба деҳаи Намозгоҳ
- деҳаи Турғоқ ба деҳаи Насими кӯҳсор
- деҳаи Мингботман ба деҳаи Шаббода
- деҳаи Тариқпоя ба деҳаи Чангоб
- деҳаи Бешкаппа ба деҳаи Гули бодом
- деҳаи Шурманқа ба деҳаи Ганҷина
- деҳаи Косабулоқ ба деҳаи Пистазор
- деҳаи Қараболчиқ ба деҳаи Қалъа
- деҳаи Тулкибулоқ ба деҳаи Хӯҷабехоб
- деҳаи Қарагаза ба деҳаи Марғзор
- деҳаи Шуртуғай ба деҳаи Сайёд
- деҳаи Кӯкабулоқ ба деҳан Зарчашма тағйир дода шаванд.
2. Номи деҳоти Испечак ба деҳоти Чоряккорон ва номи деҳаҳои зерини он:
- деҳаи Учқул ба деҳаи Меҳробод
- деҳаи Ҷайрабулоқ ба деҳаи Армуғон
- деҳаи Катасой ба деҳаи Ҳуснобод тағйир дода шаванд.
3. Номи деҳоти Куктош ба деҳоти Чоргултеппа ва номи деҳаҳои зерини он:
- деҳаи Стаханов ба деҳаи Кӯктош
- деҳаи Партизани Сурх ба деҳаи Чорсӯ
- деҳаи Қара-Камар ба деҳаи Қарияи Камар
- деҳаи Киров ба деҳаи Оби шифо
- деҳаи Янгиқурилиш ба деҳаи Навбунёд
- деҳаи Медик ба деҳаи Табибон
- деҳаи МХОС ба деҳаи Сада
- деҳаи Уртакенгаш ба деҳаи Саховат
- деҳаи Янгиобод ба деҳаи Зарнисор
- деҳаи Қизил Пахтакор ба деҳаи Пахтакор
- шаҳрчаи Камаров ба шаҳрчаи Мадад
- деҳаи Анақулобод ба деҳаи Орзӯ
- деҳаи Кӯлбулоқи боло ба деҳаи Чашмасор
- деҳаи Кӯлбулоқи поён ба деҳаи Машъал
- деҳаи Шӯрбулоқ ба деҳаи Шӯрчашма
- деҳаи Оқбулоқ ба деҳаи Себистон
- деҳаи Пахолсой ба деҳаи Чаманзор тағйир дода шаванд.
4. Номи деҳоти Қӯштеппа ба деҳоти Россия ва номи деҳаҳои зерини он:
- деҳаи Чапаев ба деҳаи Соҳибкорон
- деҳаи Киров ба деҳаи Алочабоф
- деҳаи К.Маркс ба деҳаи Чилмеҳроб
- деҳаи Шапкин ба деҳаи Фалакон
- деҳаи XXI1- Партсъезд ба деҳаи Яккатут
-деҳаи Правда 1,2,3 ба деҳаи Деҳқонобод
- деҳаи Дмитрова 1,2,3 ба деҳаи Қӯштеппа тағйир дода шаванд.
5. Номи деҳоти 40-солагии Тоҷикистон ба деҳоти Сарикиштӣ ва номи деҳаҳои зерини он:
- деҳаи Янгиобод ба деҳаи Ҷавонон
- деҳаи Насосная ба деҳаи Навбаҳор
- деҳаи 18-ӯми Партсъезд ба деҳаи Дӯстӣ
- деҳаи Подгора ба деҳаи Доманакӯҳ тағйир дода шаванд.
6. Номи деноти Оқ-Қӯрғон ба деҳоти Чимтеппа ва номи деҳаҳои зерини он:
- деҳаи Янгиобод ба деҳаи Ҳосилот
- деҳаи Крупская ба деҳаи Корвон
- деҳаи Пахтакор 1, 2 ба деҳаи Обчакорон
- деҳаи Оқ-Қӯрғон ба деҳаи Сомон
- деҳаи Коммунизм ба деҳаи Гулпарвар тағйир дода шаванд.
7. Дар деҳоти Султонобод номи деҳаҳои зерини он:
- деҳаи Абдал ба деҳаи Меҳнат
- деҳаи Келтош ба деҳаи Истиқбол
- деҳаи Кӯлбулоқ ба деҳаи Иттифоқ
- деҳаи Галлабулоқ ба деҳаи Баҳор
- деҳаи Жалабулоқ ба деҳаи Балхӣ
- деҳаи Муллоэш ба деҳаи Баракат
- деҳаи Бошбулоқ ба деҳаи Сарчашма
- деҳаи Қирма ба деҳаи Нафтобод
- деҳаи Дунгизулдӣ ба деҳаи Бӯстон
- деҳаи Қизил Қишлов ба деҳаи Лолазор
- деҳаи Арпабулоқ ба деҳаи Гулоб
- деҳаи Аввалкизак ба деҳаи Сабзазор
- деҳаи Мингботман ба деҳаи Меҳргон
- деҳаи Чегам ба деҳаи Кӯҳдоман
- деҳаи Тошбулоқ ба деҳаи Офтобрӯя
- деҳаи Ҷомбулоқ ба деҳаи Чаманоро тағйир дода шаванд.
8. Дар деҳоти Гулистон номи деҳаҳои зерини он:
- деҳаҳои Большевики боло, Большевики поён ба деҳаи Гулкорон
- деҳаи Янгиқӯрғон ба деҳаи Мавлавӣ
- деҳаи Стаханов ба деҳаи Шаҳристон
- деҳаи Қизилнишон ба деҳаи Меҳан
- деҳаи Қайргочи боло ба деҳаи Болошаҳр
- деҳаи Қайргочи поён ба деҳаи Майсазор тағйир дода шаванд.
9. Дар деҳоти Лоҳур номи деҳаҳои зерини он:
- деҳаи Янгиҳаёт ба деҳаи Ҳаёти нав
- деҳаи Тузобод ба деҳаи Наврӯз
- деҳаи Хӯҷақушқор ба деҳаи Хӯҷахушхон тағйир дода шаванд.
10. Дар деҳоти Зайнабобод номи деҳаҳои зерини он:
- деҳаи 12-ӯм км. ба деҳаи Косибон
- деҳаи Қизил-ариқ ба деҳаи Ҳоҷиён
- деҳаи Птисевод ба деҳаи Истиқлол
- деҳаи Қизил-юлдуз ба деҳаи Румӣ
- деҳаи Янги-меҳнат ба деҳаи Файзоба
- деҳаи Совнарком ба деҳаи Адолат
- деҳаи Шолипоя ба деҳаи Сароб
- деҳаи Ленин ба деҳаи Шафақ
- деҳаи Микоян ба деҳаи Садоқат
- деҳаи Қизил-Аскар ба деҳаи Гулобод
- деҳаи Ильич ба деҳаи Шараф
- деҳаи Қизил-байрақ ба деҳаи Иқбол
- деҳаи Олий-Совет ба деҳаи Оли Сомон
- деҳаи Янги-турмуш ба деҳаи Кишоварз
- деҳаи Янги-юл ба деҳаи Мавҷ тағйир дода шаванд.
11. Дар деҳоти Роҳатӣ:
- шаҳраки Нефтяник ба шаҳраки Ганҷобод тағйир дода шавад.
Раиси
Маҷлиси миллии Маҷлиси Олии
Ҷумҳурии Тоҷикистон М. Убайдуллоев
ш. Душанбе 5 июни соли 2008 № 509
