Моддаи 72. Тағйир додани сабти асноди ҳолати шаҳрвандӣ бо сабаби иваз намудани насаб, ном ва (ё) номи падар
(Қонуни ҶТ аз 26.03.2009 № 496)
1. Дар асоси сабти аснод дар бораи иваз намудани насаб, ном ва (ё) номи падар ба сабти асноди ҳолати шаҳрвандие, ки пештар нисбати шахсе, ки насаб, ном ва (ё) номи падарро иваз намудааст, тартиб дода шуда буд, тағйирот дохил карда шуда, шаҳодатномаи нав дар бораи бақайдгирии давлатии сабти асноди ҳолати шаҳрвандӣ бо назардошти тағйироти ба сабти асноди ҳолати шаҳрвандӣ дохилшуда дода мешавад (Қонуни ҶТ аз 26.03.2009 № 496).
Хориҷ карда шуд (Қонуни ҶТ аз 26.03.2009 № 496).
2. Ҳангоми иваз намудани насаб, ном ва (ё) номи падар аз тарафи падару модар маълумот дар бораи падару модар дар сабти асноди таваллуди кӯдаки ба балоғатнарасида тағйир дода мешавад (Қонуни ҶТ аз 26.03.2009 № 496).
Дар сабти асноди таваллуди кӯдаки ба балоғатрасида маълумот дар бораи падару модари ӯ бо аризаи худи ӯ (шахси ба балоғатрасида) бо тартиби муқаррарнамудаи Қонуни мазкур барои ворид намудани ислоҳ, тағйирот ва иловаҳо ба сабти асноди ҳолати шаҳрвандӣ тағйир дода мешавад.
3. Ҳангоми иваз намудани насаб аз тарафи падару модар ва номи падар дар сабти асноди таваллуди кӯдаки ба синни шонздаҳнарасида насаб ва номи падари кӯдак иваз карда мешавад (Қонуни ҶТ аз 26.03.2009 № 496).
Ҳангоми иваз намудани насаби яке аз падару модар, насаби кӯдаки онҳо, ки ба синни шонздаҳ нарасидааст, метавонад бо розигии падар ва модар, вале дар сурати набудани чунин розигӣ, бо нишондоди мақомоти васоят ва парасторӣ иваз карда шавад (Қонуни ҶТ аз 26.03.2009 № 496).
Иваз намудани номи падар ва насаби кӯдаки ба балоғатрасида бо сабаби иваз намудани насаби падару модари ӯ ва номи падар бо тартиби муқарраркардаи Қонуни мазкур барои бақайдгирии давлатии иваз намудани насаб, ном ва (ё) номи падар ба ҷо оварда мешавад (Қонуни ҶТ аз 26.03.2009 № 496).
4. Дар асоси тағйироти воридкардашуда ба сабти асноди таваллуди кӯдаки ба балоғатнарасида шаҳодатномаи нав дар бораи таваллуд дода мешавад.
