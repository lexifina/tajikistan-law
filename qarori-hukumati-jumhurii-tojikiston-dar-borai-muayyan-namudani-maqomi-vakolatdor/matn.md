Ќарори Ӣукумати Ғумӣурии Тоғикистон «Дар бораи муайян намудани мақоми ваколатдори давлатӣ оид ба ҳифзи ихтироот, намунаҳои саноатӣ, топологияҳои микросхемаҳои интегралӣ, ишораҳои ҷуғрофӣ, тамғаҳои молӣ ва тамғаҳои хизматрасонӣ (Идораи патентии Ҷумҳурии Тоҷикистон)»
Мутобиқи моддаи 3 Қонуни Ҷумҳурии Тоҷикистон «Дар бораи ихтироъ», моддаи 3 Қонуни Ҷумҳурии Тоҷикистон «Дар бораи намунаҳои саноатӣ», моддаи 3 Қонуни Ҷумҳурии Тоҷикистон «Дар бораи ҳифзи ҳуқуқии топологияҳои микросхемаҳои интегралӣ», моддаи 3 Қонуни Ҷумҳурии Тоҷикистон «Дар бораи ишораҳои ҷуғрофӣ» ва моддаи 3 Қонуни Ҷумҳурии Тоҷикистон «Дар бораи тамғаҳои молӣ ва тамғаҳои хизматрасонӣ» Ҳукумати Ҷумҳурии Тоҷикистон қарор мекунад:
Мақоми ваколатдори давлатӣ оид ба ҳифзи ихтироъ, намунаҳои саноатӣ, топологияҳои микросхемаҳои интегралӣ, ишораҳои ҷуғрофӣ, тамғаҳои молӣ ва тамғаҳои хизматрасонӣ (Идораи патентии Ҷумҳурии Тоҷикистон) Муассисаи давлатии «Маркази миллии патенту иттилоот»-и Вазорати рушди иқтисод ва савдои Ҷумҳурии Тоҷикистон муайян карда шавад.
Раиси Ҳукумати Ҷумҳурии Тоҷикистон Эмомалӣ Раҳмон аз 3 апрели соли 2012, №153 ш. Душанбе
