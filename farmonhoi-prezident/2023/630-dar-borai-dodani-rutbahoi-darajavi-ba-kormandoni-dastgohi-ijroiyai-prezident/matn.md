ФАРМОНИ ПРЕЗИДЕНТИ ҶУМҲУРИИ ТОҶИКИСТОН
Дар бораи додани рутбаҳои дараҷавӣ ба кормандони Дастгоҳи иҷроияи Президенти Ҷумҳурии Тоҷикистон
Мутобиқи моддаи 69 Конститутсияи Ҷумҳурии Тоҷикистон ва Низомномаи тартиби додани рутбаҳои дараҷавӣ ба кормандони Дастгоҳи иҷроияи Президенти Ҷумҳурии Тоҷикистон, ки таҳсилоти олии ҳуқуқӣ доранд, фармон медиҳам:
Ба кормандони Дастгоҳи иҷроияи Президенти Ҷумҳурии Тоҷикистон рутбаҳои дараҷавии зерин дода шавад:
- Ҳаётзода Фирдавс Ҷурахон - муовини якуми Роҳбари Дастгоҳи иҷроияи Президенти Ҷумҳурии Тоҷикистон - "Мушовири давлатии адлияи дараҷаи 2";
- Абдураҳим Карим - мушовири бахши ёрдамчии Президенти Ҷумҳурии Тоҷикистон оид ба масъалаҳои ҳуқуқӣ - "Мушовири давлатии адлияи дараҷаи 3";
- Шарифзода Ҷамшед Ғаниҷон - мушовири калони бахши ёрдамчии Президенти Ҷумҳурии Тоҷикистон оид ба масъалаҳои ҳуқуқӣ - "Мушовири давлатии адлияи дараҷаи 3";
- Сироҷзода Сайфиддин - мушовири бахши ёрдамчии Президенти Ҷумҳурии Тоҷикистон оид ба масъалаҳои ҳуқуқӣ - "Мушовири давлатии адлияи дараҷаи 3";
- Давлатзода Музаффар Салим - мушовири калони бахши ёрдамчии Президенти Ҷумҳурии Тоҷикистон оид ба масъалаҳои кадрҳо - "Мушовири давлатии адлияи дараҷаи 3";
- Исматзода Абдуқодир Султон - мушовири бахши ёрдамчии Президенти Ҷумҳурии Тоҷикистон оид ба масъалаҳои кадрҳо - "Мушовири давлатии адлияи дараҷаи 2";
- Холиқзода Ҷонибек - мудири бахши раёсати ҳуқуқи Дастгоҳи иҷроияи Президенти Ҷумҳурии Тоҷикистон - "Мушовири давлатии адлияи дараҷаи 3".
