# Қарори Маҷлиси Намояндагони Маҷлиси Олии Ҷумҳурии Тоҷикистон аз 10 июни соли 2015 № 100 "Дар бораи тасдиқи Созишнома дар шакли мубодилаи ёддоштҳо байни Ҳукумати Ҷумҳурии Тоҷикистон ва Дафтари Созмони амният ва ҳамкорӣ дар Аврупо дар Ҷумҳурии Тоҷикистон оид ба масъалаи пардохти андоз аз даромади шаҳрвандони Ҷумҳурии Тоҷикистон, ки фаъолияти меҳнатиро дар Дафтари Созмони амният ва ҳамкорӣ дар Аврупо дар Ҷумҳурии Тоҷикистон анҷом медиҳанд"
