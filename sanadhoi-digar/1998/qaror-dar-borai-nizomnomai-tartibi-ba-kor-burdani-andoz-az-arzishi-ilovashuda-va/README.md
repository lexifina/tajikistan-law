# Қарор дар бораи Низомномаи тартиби ба кор бурдани андоз аз арзиши иловашуда ва аксизҳо барои таҳвили тафовунии масолеҳ, маҳсулоти нимтайёр ва маснуоти такмилдиҳанда ҷиҳати истеҳсоли аслиҳаю техникаи ҳарбӣ, ҳамчунин молҳои дигари махсус ҳангоми ҳисоббаробаркунӣ байни субъектҳои хоҷагидори давлатҳои иштирокчии Иттиҳоди Давлатҳои Мустақил
