# Қарори Маҷлиси Намояндагони Маҷлиси Олии Ҷумҳурии Тоҷикистон аз 24 декабри соли 2014 № 1712 "Дар бораи тасдиқи Созишнома байни Ҷумҳурии Тоҷикистон ва Бонки Исломии Рушд (ҳамчун маъмури Барномаи "Фаел Хайр") вобаста ба татбиқи маблағгузории бебозгашти "Фаел Хайр" барои харидорӣ ва истифода намудани клиникаҳои сайёр дар деҳот дар доираи Барномаи "Фаел Хайр" оид ба таъсиси клиникаҳои сайёр дар баъзе давлатҳо ва ҷомеаи мусулмонӣ"
