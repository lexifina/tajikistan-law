Моддаи 25. Аҳдҳо оид ба ашёи осорхонавӣ ва коллексияи осорхонавии қисми ғайридавлатии Фонди осорхонаҳои Ҷумҳурии Тоҷикистон
1. Ҳангоми иҷрои аҳдҳо оид ба ихтиёрдорӣ кардани (тӯҳфа кардан, хариду фурӯш) ашёи осорхонавӣ ва коллексияи осорхонавии қисми ғайридавлатии Фонди осорхонаҳои Ҷумҳурии Тоҷикистон тӯҳфагир ё харидор ӯҳдадор аст, ки ӯҳдадориҳои дар шартнома ё қонун нисбат ба ашёи осорхонавӣ ва коллексияи осорхонавӣ пешбинишударо ба зимма бигирад. Дар ин маврид давлат ҳуқуқи афзалиятноки харидорӣ дорад. Татбиқи ҳуқуқи афзалиятноки харидории ашёи осорхонавӣ ва коллексияи осорхонавиро аз номи давлат мақоми ваколатдори давлатии соҳаи фарҳанг амалӣ менамояд.
2. Ҳангоми ба мерос гирифтани ашёи осорхонавӣ ва коллексияи осорхонавии қисми ғайридавлатии Фонди осорхонаҳои Ҷумҳурии Тоҷикистон меросгиранда ӯҳдадор аст, ки тамоми масъулияти меросгузорро нисбат ба ашёи осорхонавӣ ва коллексияи осорхонавӣ ба зимма гирад. Агар дар васиятнома муқаррароти дигар пешбинӣ нашуда бошад, баъди ба мерос гирифтани ашёи осорхонавӣ ва коллексияи осорхонавӣ меросгир ҳуқуқ дорад, ки ашёи осорхонавӣ ва коллексияи осорхонавиро тибқи салоҳдиди худ ихтиёрдорӣ намояд (Қонуни ҶТ аз 19.03.2013 № 957).
3. Агар меросгир ӯҳдадориҳои худро нисбат ба ашёи осорхонавӣ ва коллексияи осорхонавии бамеросгирифтааш иҷро накунад ё ба таври номатлуб иҷро кунад, давлат ҳуқуқ дорад, ки тибқи қонунгузории Ҷумҳурии Тоҷикистон ашёи осорхонавӣ ва коллексияи осорхонавиро харидорӣ намояд.
4. Аҳдҳо оид ба тӯҳфа кардан, хариду фурӯш ё ба мерос гирифтани ашёи осорхонавӣ ва коллексияи осорхонавии қисми ғайридавлатии Фонди осорхонаҳои Ҷумҳурии Тоҷикистон аз рӯзи бақайдгирӣ дар Феҳристи давлатии Фонди осорхонаҳои Ҷумҳурии Тоҷикистон эътибор пайдо мекунанд.
