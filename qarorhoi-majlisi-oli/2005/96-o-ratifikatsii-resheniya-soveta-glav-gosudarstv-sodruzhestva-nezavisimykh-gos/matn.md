ПОСТАНОВЛЕНИЕ МАДЖЛИСИ НАМОЯНДАГОН МАДЖЛИСИ ОЛИ РЕСПУБЛИКИ ТАДЖИКИСТАН
О ратификации Решения Совета глав государств Содружества Независимых Государств "О мерах по выполнению государствами-участниками Содружества Независимых Государств обязательств по перечислению долевых взносов в единый бюджет органов Содружества, финансируемых из бюджетных средств государств-участников Содружества Независимых Государств"
Маджлиси намояндагон Маджлиси Оли Республики Таджикистан постановляет:
1. Ратифицировать Решение Совета глав государств Содружества Независимых Государств "О мерах по выполнению государствами-участниками Содружества Независимых Государств обязательств по перечислению долевых взносов в единый бюджет органов Содружества, финансируемых из бюджетных средств государств-участников Содружества Независимых Государств", подписанное 19 сентября 2003 года в городе Ялте.
2. Министерству иностранных дел Республики Таджикистан направить ратификационную грамоту настоящего Решения в Исполнительный комитет Содружества Независимых Государств.
Председатель
Маджлиси намояндагон Маджлиси Оли
Республики Таджикистан С. Хайруллоев
