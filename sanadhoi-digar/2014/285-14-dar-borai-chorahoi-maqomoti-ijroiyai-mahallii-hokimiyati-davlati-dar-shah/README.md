# Қарори Раиси шаҳри Душанбе аз 3 июли соли 2014 № 285-14 "Дар бораи чораҳои Мақомоти иҷроияи маҳаллии ҳокимияти давлатӣ дар шаҳри Душанбе вобаста ба пешгирӣ намудани амалҳои коррупсионӣ, ҷинояткориву ҳуқуқвайронкуниҳо дар мақомоту сохтор, корхона, ташкилоту муассиса ва дигар субъектҳои хоҷагидори дар ҳудуди марзию маъмурии шаҳри Душанбе фаъолиятдошта, новобаста аз шакли моликият ва тобеияти идоравӣ, бо истифода аз насб намудани камераҳои мушоҳидавӣ, овезаҳо оид ба нарх ва тарифҳои кору хизматрасониҳои пулакӣ дар даромадгоҳҳо"
