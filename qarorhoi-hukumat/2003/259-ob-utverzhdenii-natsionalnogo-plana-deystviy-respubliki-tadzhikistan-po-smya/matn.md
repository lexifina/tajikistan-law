ПРАВИТЕЛЬСТВО РЕСПУБЛИКИ ТАДЖИКИСТАН
ПОСТАНОВЛЕНИЕ
Об утверждении Национального плана действий Республики Таджикистан по смягчению последствий изменения климата
Для выполнения обязательств Рамочной Конвенции Организации Объединенных Наций об изменении климата, минимизации антропогенного воздействия на климатическую систему и содействия адаптации к изменению климата Правительства Республики Таджикистан постановляет:
1. Утвердить Национальный план действий Республики Таджикистан по смягчению последствий изменения климата.
2. Соответствующим министерствам и ведомствам Республики Таджикистан в планировании и осуществлении государственной политики учитывать основные положения, и мероприятия Национального плана действий Республики Таджикистан по смягчению последствий изменения климата.
3. Главному управлению по гидрометеорологии и наблюдений за природной средой Министерства охраны природы Республики Таджикистан осуществлять координацию реализации Национального плана действий Республики Таджикистан по смягчению последствий изменения климата.
4. Министерству экономики и торговли Республики Таджикистан содействовать в привлечении зарубежных инвестиций для обеспечения выполнения соответствующих мероприятий Национального плана действий Республики Таджикистан по смягчению последствий изменения климата.
5. Министерству иностранных дел Республики Таджикистан в установленном порядке направить в секретариат Рамочной Конвенции Организации Объединенных Наций уведомление об утверждении Национального плана действий Республики Таджикистан по смягчению последствий изменения климата.
