# Қарори Ҳукумати Ҷумҳурии Тоҷикистон аз 31 октябри соли 2009 № 588 "Дар бораи ҳисоботи Раиси Вилояти Мухтори Кӯҳистони Бадахшон оид ба рафти иҷрои қарори Ҳукумати Ҷумҳурии Тоҷикистои аз 1 августи соли 2008 № 393 "Дар бораи Нақшаи чорабиниҳо ҷиҳати таъмини иҷрои дастуру супоришҳои Президенти Ҷумҳурии Тоҷикистон, ки ҳангоми сафари корӣ, ба шаҳри Хоруғ, ноҳияҳои Ванҷ, Рӯшон, Ишкошим, Роштқалъа дар вохӯрӣ бо роҳбарон ва фаъолони Вилояти Мухтори Кӯҳистони Бадахшон доир ба вазъи иқтисодиву иҷтимоии вилоят ва вазифаҳо барои солҳои оянда (рӯзҳои 18-20 июли соли 2008) гузошта шудаанд"
