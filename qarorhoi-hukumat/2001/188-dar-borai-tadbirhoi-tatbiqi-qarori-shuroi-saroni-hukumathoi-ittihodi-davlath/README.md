# Қарори Ҳукумати Ҷумҳурии Тоҷикистон аз 17 апрели соли 2001, № 188 "Дар бораи тадбирҳои татбиқи қарори Шӯрои сарони ҳукуматҳои Иттиҳоди Давлатҳои Мустақил аз 25 январи соли 2000 оид ба Низомнома дар бораи манбаи умумии маълумот оид ба муҳоҷирати ғайриқонунӣ ва ашхосе,ки тибқи қонунгузории миллии амалкунанда воридшавии онҳо ба давлатҳои иштирокчии Созишномаи ҳамкории давлатҳои узви Иттиҳоди Давлатҳои Мустақил дар мубориза алайҳи муҳоҷирати ғайриқонунӣ манъ аст ва тартиби табодули иттилоот дар хусуси муҳоҷирати ғайриқонунӣ"
