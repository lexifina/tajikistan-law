Моддаи 5. Дахлнопазирии Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллат
1. Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллат ва аъзои оилаи ӯ ҳуқуқи дахлнопазирӣ доранд.
2. Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллат барои амалҳояш дар давраи иҷрои ваколатҳои Раиси Шӯрои Олии Ҷумҳурии Тоҷикистон - Сарвари давлат, Президенти Ҷумҳурии Тоҷикистон ва салоҳияти Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллат ба ҷавобгарӣ кашида намешавад.
3. Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллатро дастгир намудан, ба ҳабс гирифтан, кофтуков кардан ва маҷбуран овардан манъ аст.
4. Дахлнопазирӣ ба моликият, ҳамчунин моликияти аъзои оила, ба манзили истиқоматӣ, бинои хизматӣ, нақлиёт, воситаҳои алоқа, мукотиба ва ҳуҷҷатҳои Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллат татбиқ мегардад. Ба моликияти Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллат ва аъзои оилаи ӯ ягон маҳдудият гузошта намешавад.
5. Сирри бонкӣ ва дахлнопазирии ҳисобҳои бонкии Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллат ва аъзои оилаи ӯ кафолат дода мешавад.
