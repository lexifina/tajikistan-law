# Қарори Ҳукумати Ҷумҳурии Тоҷикистон аз 5 марти соли 1999, № 59 "Дар бораи лоиҳаи Созишномаи умумӣ миёни Ҳукумати Ҷумҳурии Тоҷикистон ва Бонки муштараки "Осиёи Марказӣ" оиди ҳамкорӣ ва фаъолияти муштараки тарафҳо ҷиҳати ба Ҷумҳурии Тоҷикистон ҷалб намудани сармоягузориҳои хориҷӣ, хадамоти лозим дар заминаи қарзҳои дарозмуддат ва кӯтоҳмуддат, ки ба Ҷумҳурии Тоҷикистон ҷалб менамоянд ва ҳамчунин рушди бозори қоғазҳои қимматнок дар Ҷумҳурии Тоҷикистон"
