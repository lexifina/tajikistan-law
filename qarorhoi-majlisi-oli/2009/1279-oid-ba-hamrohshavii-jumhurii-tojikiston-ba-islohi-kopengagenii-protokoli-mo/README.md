# Қарори Маҷлиси намояндагони Маҷлиси Олии Ҷумҳурии Тоҷикистон аз 1 апрели соли 2009 № 1279 "Оид ба ҳамроҳшавии Ҷумҳурии Тоҷикистон ба ислоҳи Копенгагении протоколи Монреал оид ба моддаҳои вайронкунандаи қабати озони Конвенсияи Вена дар бораи ҳифзи қабати озон, ки 25 ноябри соли 1992 дар Ҷаласаи чоруми Тарафҳо, ислоҳи Монреалии протоколи Монреал оид ба моддаҳои вайронкунандаи қабати озони Конвенсияи Вена дар бораи ҳифзи қабати озон, ки 17 сентябри соли 1997 дар Ҷаласаи нӯҳуми Тарафҳо ва ислоҳи Пекинии протоколи Монреал оид ба моддаҳои вайронкунандаи қабати озони Конвенсияи Вена дар бораи ҳифзи қабати озон, ки 3 декабри соли 1999 дар Ҷаласаи ёздаҳуми Тарафҳо қабул гаштаанд"
