МАҶЛИСИ МИЛЛИИ МАҶЛИСИ ОЛИИ ҶУМҲУРИИ ТОҶИКИСТОН
ҚАРОР
Оид ба тағйир додани номи баъзе маҳалҳои аҳолинишини шаҳри Кӯлоб, ноҳияҳои Носири Хусрав, Шаҳритус, Шӯрообод, Бохтар, Абдураҳмони Ҷомӣ ва Ёвони вилояти Хатлон
Пешниҳоди Ҳукумати Ҷумҳурии Тоҷикистонро "Дар бораи пешниҳодҳои Маҷлиси вакилони халқи вилояти Хатлон "Оид ба тағйир додани номи баъзе маҳалҳои аҳолинишини шаҳри Кӯлоб" тахти № 688 аз 3 декабри соли 2012, "Оид ба тағйир додани номи баъзе маҳалҳои аҳолинишини ноҳияи Носири Хусрав" таҳти № 689 аз 3 декабри соли 2012, "Оид ба тағйир додани номи баъзе маҳалҳои аҳолинишини ноҳияи Шаҳритус" таҳти № 690 аз 3 декабри соли 2012, "Оид ба тағйир додани номи баъзе маҳалҳои аҳолинишини ноҳияи Шӯрообод" таҳти № 691 аз 3 декабри соли 2012, "Оид ба тағйир додани номи баъзе маҳалҳои аҳолинишини ноҳияи Бохтар" таҳти № 692 аз 3 декабри соли 2012, "Оид ба тағйир додани номи баъзе маҳалҳои аҳолинишини ноҳияи Абдураҳмони Ҷомӣ" таҳти № 693 аз 3 декабри соли 2012, "Оид ба тағйир додани номи баъзе маҳалҳои аҳолинишини ноҳияи Ёвон" таҳти № 694 аз 3 декабри соли 2012 баррасӣ намуда, мутобиқи моддаи 23 Қонуни конститутсионии Ҷумҳурии Тоҷикистон "Дар бораи тартиби ҳалли масъалаҳои сохти марзиву маъмурии Ҷумҳурии Тоҷикистон" Маҷлиси миллии Маҷлиси Олии Ҷумҳурии Тоҷикистон қарор мекунад:
Дар шаҳри Кӯлоб номи деҳаҳои зерин:
деҳаи Луликутал ба деҳаи Андароби деҳоти Зарбдор
деҳаи Бештигирмон ба деҳаи Панҷосиёби деҳоти Зарбдор
деҳаи Ҷерқалъа ба деҳаи Зарқалъаи деҳоти Зиракӣ
деҳаи Чорводор ба деҳаи Нуристони деҳоти Зиракӣ
деҳаи Ҷангалбошӣ ба деҳаи Чашмасори деҳоти Зиракӣ
деҳаи Чоқтемур ба деҳаи Бахтободи деҳоти Зиракӣ
деҳаи Афтолуқ ба деҳаи Офтоблиқои деҳоти Зиракӣ
Дар ноҳияи Носири Хусрав номи деҳоти Комсомол ба деҳоти Наврӯз ва номи деҳаҳои зерини он:
деҳаи Вагон-қишлоқ ба деҳаи 20-солагии Истиқлолияти деҳоти Фирӯза
деҳаи ба номи Исо-Намоз ба деҳаи Навободи деҳоти Фирӯза
деҳаи Янгибоғ ба деҳаи Ваҳдати деҳоти Фирӯза
деҳаи Қашқа ба деҳаи Дӯстии деҳоти Фирӯза
Дар ноҳияи Шаҳритус номи деҳаҳои зерин:
деҳаи Солтиқ ба деҳаи Устокорони деҳоти Пахтаобод
деҳаи 1-май ба деҳаи Ваҳдати деҳоти Пахтаобод
деҳаи Бошчорбоғ ба деҳаи Чорбош деҳоти Пахтаобод
деҳаи Қизилобод ба деҳаи Дӯстии деҳоти ба номи Худойназар Холматов
Дар ноҳияи Шӯрообод номи деҳаҳои зерин:
деҳаи Ҷирк ба деҳаи Роҳи нави деҳоти Даштиҷум
деҳаи Лов ба деҳаи Ваҳдати деҳоти Даштиҷум
Дар ноҳияи Бохтар номи деҳаҳои зерин:
деҳаи ба номи Калинин ба деҳаи ба номи Сирож Фаттоеви деҳоти Сарвати Истиқлол
деҳаи ба номи Ленин ба деҳаи ба номи Куган Гулови деҳоти Сарвати Истиқлол
Дар ноҳияи Абдураҳмони Ҷомӣ номи деҳаҳои зерин:
деҳаи ба номи Нахимов ба деҳаи Чашмасори деҳоти ба номи Калинин
деҳаи ба номи Чапаев ба деҳаи Обшорони деҳоти ба номи Калинин
деҳаи Лесхоз ба деҳаи Меҳргони деҳоти ба номи Калинин
деҳаи ба номи Куйбишев ба деҳаи ба номи Мирзо Турсунзодаи деҳоти Яккатут
деҳаи ба номи Карл Маркс ба деҳаи Хуросони деҳоти Яккатут
деҳаи Аскари Сурх ба деҳаи ба номи Нусратулло Махсуми деҳоти Яккатут
деҳаи Красная Звезда ба деҳаи Ҷовидони деҳоти Яккатут
деҳаи Ленин-юлӣ ба деҳаи Баҳористони деҳоти Арал
деҳаи Янгидеҳқон ба деҳаи Файзбори деҳоти Арал
деҳаи Ленинизм ба деҳаи Зафарободи деҳоти Арал
деҳаи ба номи Калинин ба деҳаи Гулободи деҳоти Арал
Дар ноҳияи Ёвон номи деҳоти Озодӣ ба деҳоти ба номн Ҳасан Ҳусейнов ва деҳоти Оби Мукӣ ба деҳоти Обшорон
тағйир дода шаванд.
Раиси
Маҷлиси миллии Маҷлиси Олии
Ҷумҳурии Тоҷикистон М. Убайдуллоев
