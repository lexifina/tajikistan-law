Статья 34.
1.При голосовании по каждому вопросу депутат Маджлиси намояндагон имеет один голос и подает его за принятие решения или против него либо воздерживается от принятия решения.
2. Депутат обязан обеспечить надлежащее хранение и использование карточки для голосования. Свое право на голосование он осуществляет лично. Соблюдение требования о необходимости личного голосования депутата Маджлиси намояндагон как существенный элемент надлежащего порядка принятия законов является обязательным.
3. Карточки для голосования выдаются группой по техническому обслуживанию электронной системы по предъявлении удостоверения депутата Маджлиси намояндагон. При утере карточки для голосования новая карточка выдается депутату по его письменному заявлению.
4. Депутат, отсутствовавший во время голосования, не вправе подать свой голос по истечении времени, отведенного для голосования.
