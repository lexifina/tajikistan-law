# Қарори Ҳукумати Ҷумҳурии Тоҷикистон аз 31 марти соли 2003, № 145 "Дар бораи тасдиқ намудани Тартиби иёр гирифтан ва тамға задани маснуоти аз металлҳои қиматбаҳо сохташуда, Тартиби литсензиякунонии навъҳои ҷудогонаи фаъолият оид ба истеҳсол, истифода ва гардиши металлҳои қиматбаҳо ва сангҳои қиматбаҳо аз ҷониби шахсони ҳуқуқӣ ва воқеӣ ва Феҳристи муваққатии корҳое, ки аз онҳо ҳаққи иёр (пардохти иёр) рӯёнда мешаванд"
