ФАРМОНИ ПРЕЗИДЕНТИ ҶУМҲУРИИ ТОҶИКИСТОН
Дар бораи таъсиси Фонди Асосгузори сулҳу ваҳдати миллӣ-Пешвои миллат
Мутобиқи моддаи 12 Қонуни конститутсионии Ҷумҳурии Тоҷикистон "Дар бораи Асосгузори сулҳу ваҳдати миллӣ-Пешвои миллат" бо мақсади амалӣ намудани иқдомҳои созандаи Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллат фармон медиҳам:
1. Аз 1 январи соли 2018 Фонди Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллат таъсис дода шавад.
2. Дастгоҳи иҷроияи Президенти Ҷумҳурии Тоҷикистон масъалаҳои ташкилию ҳуқуқии фонди мазкурро ҳал намояд.
3. Тартиби ихтиёрдорӣ намудани маблағҳои Фонди Асосгузори сулҳу ваҳдати миллӣ - Пешвои миллат тасдиқ карда шавад (замима мегардад).
4. Маблағгузорӣ аз буҷети давлатӣ ба фонди мазкур баъди қатъи ваколати президентии Асосгузори сулҳу ваҳдати миллӣ-Пешвои миллат амалӣ карда шавад.
