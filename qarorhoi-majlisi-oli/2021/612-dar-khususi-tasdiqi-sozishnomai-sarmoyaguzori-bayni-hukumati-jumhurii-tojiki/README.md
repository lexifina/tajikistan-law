# Қарори Маҷлиси намояндагони Маҷлиси Олии Ҷумҳурии Тоҷикистон аз 29 декабри соли 2021, №612 "Дар хусуси тасдиқи Созишномаи сармоягузорӣ байни Ҳукумати Ҷумҳурии Тоҷикистон ва Ҷамъияти дорои масъулияти маҳдуди Корхонаи муштараки "Зарафшон" оид ба коркарди маҷмӯии конҳои "Тарор", "Ҷилав" ва бунёди корхонаи металлургӣ барои барориши маҷмӯии тилло ва мис тавассути оксидкунии фишурда аз хокаҳои бойгардонидашудаи тилло ва мис дар шаҳри Панҷакенти вилояти Суғд"
