Ҳукумати Ҷумҳурии Тоҷикистон
ҚАРОР
Дар бораи Муассисаи давлатии "Мактаби ҷумҳуриявии маҳорати олии варзишӣ оид ба намудҳои якҳарба"
(қарори Ҳукумати ҶТ аз 30.09.2021 №424)
Мутобиқи моддаҳои 52 ва 132 Кодекси граждании Ҷумҳурии Тоҷикистон ва бо мақсади рушди минбаъдаи варзиши намуди якҳарба (ИТФ) дар кишвар Ҳукумати Ҷумҳурии Тоҷикистон қарор мекунад (қарори Ҳукумати ҶТ аз 30.09.2021 №424).:
1. Муассисаи давлатии "Муассисаи давлатии "Мактаби ҷумҳуриявии маҳорати олии варзишӣ оид ба намудҳои якҳарба" дар доираи воҳидҳои кории амалкунандаи ташкилотҳои системаи Кумитаи кор бо ҷавонон ва варзиши назди Ҳукумати Ҷумҳурии Тоҷикистон таъсис дода шавад (қарори Ҳукумати ҶТ аз 11.07.2015 № 465, аз 30.09.2021 №424).
2. Ба номгӯи ташкилотҳои системаи Кумитаи кор бо ҷавонон ва варзиши назди Ҳукумати Ҷумҳурии Тоҷикистон, ки бо қарори Ҳукумати Ҷумҳурии Тоҷикистон аз 28 декабри соли 2006 № 609 тасдиқ шудааст, сархати дувоздаҳум дар таҳрири зайл илова карда шавад (қарори Ҳукумати ҶТ аз 30.09.2021 №424):
"Муассисаи давлатии "Мактаби ҷумҳуриявии маҳорати олии варзишӣ оид ба намудҳои якҳарба" (қарори Ҳукумати ҶТ аз 30.09.2021 №424).
3. Кумитаи кор бо ҷавонон ва варзиши назди Ҳукумати Ҷумҳурии Тоҷикистон барои таъмини Муассисаи давлатии "Муассисаи давлатии "Мактаби ҷумҳуриявии маҳорати олии варзишӣ оид ба намудҳои якҳарба" бо биноҳои маъмурию таълимӣ, таҷҳизот ва воситаҳои таълимию методӣ чораҳои зарурӣ андешад (қарори Ҳукумати ҶТ аз 11.07.2015 № 465, аз 30.09.2021 №424).
4. Маблағгузории Муассисаи давлатии "Муассисаи давлатии "Мактаби ҷумҳуриявии маҳорати олии варзишӣ оид ба намудҳои якҳарба" дар доираи маблағҳои барои муассисаҳои зертобеи Кумитаи кор бо ҷавонон ва варзиши назди Ҳукумати Ҷумҳурии Тоҷикистон дар соли 2009 ва солҳои минбаъда пешбинишуда амалӣ карда шавад (қарори Ҳукумати ҶТ аз 11.07.2015 № 465, аз 30.09.2021 №424).
