# Қарори Ҳукумати Ҷумҳурии Тоҷикистон аз 30 июни соли 2007, № 344 "Дар бораи тасдиқи Қарори Шӯрои байнидавлатии Иттиҳоди иқтисодии Евразия (дар сатҳи сарони ҳукуматҳо) оид ба Принсипҳои умумии ташаккул ва истифодабарии тарифҳои роҳи оҳан барои ҳамлу нақли борҳо байни истгоҳҳои роҳи оҳани давлатҳои аъзои Иттиҳоди иқтисодии Евразия ва Тартиби муқаррарсозии коэффисиентҳои пастшаванда ва андозаи тарифҳои батаваққуф барои ҳамлу нақли борҳо байни истгоҳҳои роҳи оҳани давлатҳои аъзои Иттиҳоди иқтисодии Евразия"
