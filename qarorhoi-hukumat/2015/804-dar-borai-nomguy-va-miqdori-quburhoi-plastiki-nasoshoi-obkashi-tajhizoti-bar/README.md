# Қарори Ҳукумати Ҷумҳурии Тоҷикистон аз 30 декабри соли 2015 № 804 "Дар бораи Номгӯй ва миқдори қубурҳои пластикӣ, насосҳои обкашӣ, таҷҳизоти барқӣ, зеристгоҳи барқӣ, қисмҳои эҳтиётии насосҳои обкашӣ, таҷҳизоти барқӣ ва зеристгоҳи барқии аз ҷониби Ширкати муштараки Хитой-Тоҷикистон "Ҷунтай-Хатлон Синсилу" барои ба гардиши кишоварзӣ ворид намудани заминҳо, аз худ намудани заминҳои нав ва обёрӣ намудани чарогоҳҳо дар ноҳияҳои Данғара, Ҷиликӯл, Қубодиён, Шаҳритус ва Носири Хусрави вилояти Хатлон воридшаванда, ки аз андози арзиши иловашуда ва боҷи гумрукӣ озод карда мешаванд"
