ҚОНУНИ ҶУМҲУРИИ ТОҶИКИСТОН
БОБИ 1. МУҚАРРАРОТИ УМУМӢ
Моддаи 1. Қонунгузории Ҷумҳурии Тоҷикистон дар бораи таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 2. Мафҳумҳои асосӣ
Моддаи 3. Сиёсат ва кафолатҳои давлатӣ дар соҳаи таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 4. Худмухтории муассисаҳои олии таълимӣ ва озодиҳои академӣ
Моддаи 5. Вазъи ҳуқуқӣ, навъ ва номгӯи муассисаи олии таълимӣ
БОБИ 2. СИСТЕМАИ ТАҲСИЛОТИ ОЛИИ КАСБӢ ВА ТАҲСИЛОТИ КАСБИИ БАЪД АЗ МУАССИСАИ ОЛИИ ТАЪЛИМӢ
Моддаи 6. Сохтори системаи таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 7. Стандартҳои давлатии таълимӣ ва барномаҳои таълимии таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 8. Зинаҳои таҳсилоти олии касбӣ, мӯҳлат ва шаклҳои аз бар кардани он
Моддаи 9. ҳуҷҷатҳо доир ба таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 10. Вазифаҳо ва сохтори муассисаҳои олии таълимӣ
Моддаи 11. Тартиби таъсис, азнавташкилдиҳӣ, барҳамдиҳӣ, литсензиякунонӣ ва аккредитатсияи муассисаҳои олии таълимӣ
Моддаи 12. Қабул ба муассисаи олии таълимӣ ва тайёр кардани мутахассисони дорои таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 13. Идоракунии муассисаи олии таълимӣ
Моддаи 14. Иттиҳодия (ассотсиатсия, иттифоқ)-ҳои системаи таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 15. Иттиҳодияҳои ҷамъиятӣ дар системаи таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
БОБИ 3. ФАЪОЛИЯТИ ТАЪЛИМӢ, МЕТОДӢ ВА ИЛМИИ МУАССИСАҲОИ ОЛИИ ТАЪЛИМӢ
Моддаи 16. Забони таълим
Моддаи 17. Мазмуни таълим
Моддаи 18. Ташкили корҳои таълимӣ ва методӣ
Моддаи 19. Ташкили корҳои илмӣ-таҳқиқотӣ ва эҷодӣ
БОБИ 4. СУБЪЕКТҲОИ ФАЪОЛИЯТИ ТАЪЛИМИЮ ИЛМӢ ДАР СИСТЕМАИ ТАҲСИЛОТИ ОЛИИ КАСБӢ ВА ТАҲСИЛОТИ КАСБИИ БАЪД АЗ МУАССИСАИ ОЛИИ ТАЪЛИМӢ, ҲУҚУҚУ ӮҲДАДОРИҲОИ ОНҲО
Моддаи 20. Ҳуқуқ ва ӯҳдадориҳои донишҷӯи муассисаи олии таълимӣ
Моддаи 21. Бо кор таъмин намудани хатмкардагони муассисаҳои олии таълимӣ
Моддаи 22. Имтиёзҳо ба шахсоне, ки дар баробари кор дар муассисаи олии таълимӣ таҳсил мекунанд
Моддаи 23. Шунавандагони муассисаҳои системаи таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 24. Докторантҳо, аспирантҳо, унвонҷӯён
Моддаи 25. Ҳуқуқу ӯҳдадориҳои кормандони муассисаҳои олии таълимӣ
Моддаи 26. Омодагӣ ва такмили ихтисоси кормандони илмию омӯзгорӣ
Моддаи 27. Унвонҳои илмӣ
Моддаи 28. Эътироф ва муқаррар кардани баробарии ҳуҷҷатҳои давлатҳои хориҷӣ дар бораи таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ ва унвонҳои илмӣ
БОБИ 5. ИДОРАИ СИСТЕМАИ ТАҲСИЛОТИ ОЛИИ КАСБӢ ВА ТАҲСИЛОТИ КАСБИИ БАЪД АЗ МУАССИСАИ ОЛИИ ТАЪЛИМӢ
Моддаи 29. Мақомоти идоракунии системаи таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 30. Салоҳияти Ҳукумати Ҷумҳурии Тоҷикистон дар соҳаи таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 31. Салоҳияти мақомоти давлатии идораи маориф дар соҳаи таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
Моддаи 32. Салоҳияти Идораи аттестатсияи муассисаҳои таълимии мақомоти идораи давлатӣ
Моддаи 33. Назорати давлатӣ ба сифати таҳсилоти олии касбӣ ва таҳсилоти касбии баъд аз муассисаи олии таълимӣ
