Статья 454.1. Подсудность судам Таджикской ССР гражданских дел по спорам, в которых участвуют иностранные граждане, лица без гражданства, иностранные предприятия и организации, а также по спорам, по которым хотя бы одна из сторон проживает за границей
Подсудность судам Таджикской ССР гражданских дел по спорам, в которых участвуют иностранные граждане, лица без гражданства, иностранные предприятия и организации, а также по спорам, по которым хотя бы одна из сторон проживает за границей, определяется законодательством Союза ССР, а в случаях, не предусмотренных законодательством Союза ССР, - исходя из правил подсудности, установленных настоящим Кодексом.
